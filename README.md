## Como abrir os notebooks

**Google Colab** — sem instalar nada: abra o notebook aqui no GitHub e substitua `github.com` por `githubtocolab.com` na barra de endereços.

**Localmente** — com Python 3 instalado:

```bash
git clone https://github.com/gstvhortencio/ebac-analise-de-dados.git
cd ebac-analise-de-dados
pip install notebook
jupyter notebook
```

Os notebooks deste módulo usam apenas a biblioteca padrão do Python — não há dependências a instalar.
